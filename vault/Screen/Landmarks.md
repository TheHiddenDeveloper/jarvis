# Screen Landmarks

Stable UI element positions learned from successful vision/click operations.
Coordinates are **percentages** of the full screen (0–100) and are stored with the
resolution they were captured at. If the monitor layout or resolution changes,
re-locate landmarks with `click_on`/`detect_objects_in_image` and re-record.
